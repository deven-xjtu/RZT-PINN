# An RZT-PINN Framework for Laminated Composite Plates

This repository contains the implementation for the manuscript **“An RZT-PINN framework with energy-driven adaptive sampling for deformation analysis of laminated composite plates.”** 

The manuscript has been submitted to *Composite Structures*.

## Programs

- `case1_Sandwich composite laminate/case1-RZTPINN.py` - sandwich composite laminate.
- `case2_Honeycomb core laminate/case2-RZTPINN.py` - honeycomb structure.
- `case3_Multi-directional laminate/case3_RZTPINN.py` - multidirectional laminate.
